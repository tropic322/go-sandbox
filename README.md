## Инициализация репозитория
* git init - создает новый локальный репозиторий
* git clone <url> - клонирует существующий репозиторий
## Управление файлами
* git status - показывает текущее состояние репозитория
* git add <file> - добавляет указанный файл в индекс
* git add . - добавляет все измененные файлы в индекс
* git add -A - добавляет все изменения, включая удаленные файлы
## Коммиты
* git commit -m "Сообщение" - создает новый коммит с сообщением
* git commit --amend - редактирует последний коммит
* git log - показывает историю коммитов
* git log --oneline - компактная версия истории коммитов
## Ветки
1. git branch - показывает список веток
2. git branch <name> - создает новую ветку
3. git checkout <name> - переключается на указанную ветку
4. git checkout -b <name> - создает и переключается на новую ветку
5. git merge <branch> - сливает ветку в текущую
6. git push origin --delete <branch> - удаляет ветку на удаленном репозитории
## Работа с удаленным репозиторием
* git remote add origin <url> - добавляет связь с удаленным репозиторием
* git push origin <branch> - отправляет ветку на удаленный репозиторий
* git pull origin <branch> - получает изменения из удаленного репозитория
* git fetch - загружает изменения из удаленного репозитория
## Отмена изменений
* git reset --soft HEAD - отменяет коммит, сохраняя изменения
* git reset --hard HEAD - полностью удаляет все изменения
* git checkout -- <file> - восстанавливает файл из последнего коммита
## Конфликты
* git add <file> - разрешает конфликт после ручного редактирования
* git commit - завершает разрешение конфликта
* git push -u origin <branch> - устанавливает связь с удаленной веткой
